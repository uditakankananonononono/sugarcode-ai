# Riboswitch

Riboswitch: A design tool for RNA-based biosensors that change conformation in response to target metabolites, providing high sensitivity for molecular detection. It generates sequences and visualizes 2D folded structures while simulating response curves. Riboswitch enables the development of monitoring tools for diverse applications in synthetic biology and diagnostics.
