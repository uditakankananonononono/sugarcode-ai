# BioImage AI

BioImage AI: A computer vision module for automated analysis of microscopy images, performing tasks like cell counting and morphology assessment. It uses deep learning to correct segmentation errors and provides quantitative data on culture health. BioImage AI accelerates the analysis of phenotypic screens, turning visual data into actionable scientific insights.
