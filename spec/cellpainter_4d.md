# CellPainter 4D

CellPainter 4D: A temporal simulation engine for cell morphology that models how cell shapes and features change over time. It provides event timelines and numerical traces of morphological drift during differentiation. CellPainter 4D offers a dynamic view of responses, helping researchers understand the temporal sequence of cellular morphological changes.
